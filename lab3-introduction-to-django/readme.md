# Django Tutorials

## 🧩 Часть 1 - Создание проекта и первого приложения (polls), написание базовой view и настройка маршрутов

### Основные шаги
- создание проекта через django-admin startproject
- добавление приложения: python manage.py startapp polls
- настройка urls.py для проекта и приложения
- написание первой view, возвращающей HTTP-ответ
- запуск dev-сервера и проверка результата

## 🗂️ Часть 2 - Работа с моделями и базой данных, использование ORM, подключение приложения к админке.

### Основные шаги
- создание моделей Question и Choice
- выполнение миграций (makemigrations, migrate)
- работа с ORM через Django shell
- регистрация моделей в админ-интерфейсе (admin.py)

## 🎯 Часть 3 - шаблоны и динамические страницы, обработка ошибок, именование маршрутов.

### Основные шаги
- получение данных из БД и передача их в шаблоны
- создание HTML-шаблонов для отображения данных
- использование get_object_or_404 для 404-страниц
- именование URL и упрощение шаблонов с помощью {% url %}

## 📝 Часть 4 - Формы, работа с POST-запросами и generic views (классовые представления)

### Основные шаги
- создание и обработка HTML-форм
- валидация пользовательских данных
- реализация POST/GET-логики во view
- использование generic views для упрощения CRUID-операций

## 🛠️ Часть 5 - Тестирование приложения

### Основные шаги
- написание тестов для моделей и представлений
- использование django.test.TestCase
- запуск тестов: python manage.py test
- анализ результатов и покрытие кода тестами

## 💻 Часть 6 - работа со статическими файлами (CSS, изображения, JS)

### Основные шаги
- настройка параметров STATIC_URL и STATICFILES_DIR в settings.py
- подключение CSS и изображений к шаблонам
- использование collectstatic для продакшена

## 📊 Часть 7 - настройка и кастомизация административного интерфейса Django

### Основные шаги
- изменение отображения моделей (поля, фильтры, поиск)
- настройка панели администратора
- улучшение интерфейса редактирования связанных объектов

# ✅ Итог
В ходе прохождения всех 7 частей были изучены:
- структура Django-проекта и принципы MVC (Model-View-Controller)
- работа с моделями, шаблонами и маршрутизацией
- обработка данных форм и реализация CRUD-функционала
- написание и выполенение тестов
- настройка статики и админ-панели

**Результат:** полностью рабочее приложение опросов (**Polls app**), созданное по официальной документации Django
