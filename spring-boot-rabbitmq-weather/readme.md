# Distributed Weather Forecast Aggregation System
**Spring Boot + RabbitMQ + OpenWeatherMap API**

## Описание проекта
В рамках лабораторной работы была разработана распределенная система для агреграции погодных данных, основанная на микросервисной архитектуре.
Каждый сервис выполняет отдельную роль в процессе получения, обработки и объединения прогнозов погоды для заданных городов.

Система реализует **паттерн Aggregator** и взаимодействует через **RabbitMQ** как брокер сообщений.
В качестве источника данных используется **OpenWeatherMap API**.

## Архитектура системы
Проект состоит из 4 основных компонетов:
### 1. **weather-api-service**
- Принимает запросы от фронтенда через REST API.
- Отправляет задачи в очередь `weather.request.queue` через RabbitMQ.
- Ожидает и агрегирует ответы от других сервисов.
- Использует асинхронную обработку с помощью `CompletableFuture`.

### 2. **weather-consumer-service**
- Получает сообщения с запросами на прогноз погоды.
- Делает HTTP-запрос к **OpenWeatherMap API** для каждого города.
- Формирует ответ и отправляет его обратно в очередь `weather.response.queue`.
- Использует ручное подтвеждение доставки сообщений (`manual ACK`).

### 3. **weather-aggregator-service**
- Реализует паттерн **Aggregator**.
- Собирает все частичные ответы по `correlationId`.
- После получения всех данных формирует сводный отчет и отправляет его в очередь `weather.aggregated.queue`.
- Имеет планировщик (`@Scheduled`) для очистки устаревших процессов агрегации.

### 4. **weather-frontend**
- Простой одностраничный интерфейс на HTML, CSS и JavaScript.
- Позволяет ввести список городов и отправить запрос к API.
- Отображает результаты в виде таблицы.
- Работает с REST-endpoint

## Используемые технологии
- **Java 21 (Amazon Corretto)**
- **Spring Boot 3.3.5**
- **OpenWeatherMap API**
- **Maven**
- **Docker**
- **HTML / CSS / JS**

## Результаты работы
- Разработана распределенная микросервисная система для получения и агрегации погодных данных.
- Сервисы успешно взаимодействуют через **RabbitMQ**, обмениваясь сообщениями в формате JSON.
- Интеграция с **OWM API** обеспечивает получение актуальных погодных данных.
- Данные агрегируются и отображаются на веб-интерфейсе.
