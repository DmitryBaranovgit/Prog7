#️ Лабораторная работа №4 - Формы и аутентификация в Django

#️#️ 📄 **Применение форм в Django. Аутентификация и регистрация пользователя**

Данный проект расширяет стандартное приложение *Polls*
- форму для создания новых опросов
- систему аутентификации пользователей (регистрация, вход и выход из системы)

#️#️ 🎯 Цели работы
1. Научиться создавать и обрабатывать форму в Django
2. Реализовывать систему регистрации, входа и выхода пользователей с использованием встроенного моделя `django.contrib.auth`.
3. Интегрировать форму и серверную логику в приложение
4. Улучшить пользовательский интерфейс с помощью Bootstrap и системы сообщений.

#️#️ 🧩 Реализованный функционал

#️#️#️ 1. Форма создания опросов
- Добавлена страница для **создания новых опросов**.
- Форма включает:
- - поле для ввода **текста вопроса**
- - текстовую область для **вариантов ответов**, каждый вариант на отдельной строке
- После отправки формы:
- - создается объект `Question`
- - автоматически создаются связанные объекты `Choice` для каждого введенного варианта ответа.

#️#️#️ 2. Регистрация и аутентификация пользователей
- Реализованы страницы:
- - **регистрации** (`register_view`)
- - **входа** (`login_view)
- - **выхода** (`logout_view`)
- Используется встроенная модель `User` и функции `authenticate()`, `login()`, `logout()`
- Добавлены уведомления через систему сообщений (`django.contrib.messages`)
  
#️#️#️ 3. Шаблоны и навигация
- Созданы шаблоны:
- - `login.html`
- - `register.html`
- Обновлен шаблон `base.html`:
- - добавлены кнопки `Login`, `Register`, `Logout`
- - отображается приветствие пользователя (`Hello, username!`) при входе в систему
- Все страницы стилизованы с использованием **Bootstrap 5**

#️#️#️ 4. Перенаправления и уведомления
- После входа или выхода пользователь перенаправляется на `/polls`.
- Реализованы уведомления:
- - <Регистрация успешна!>
- - <Неверное имя пользователя или пароль.>
- - <Вы успешно вышли из системы.>
- Уведомления отображаются на всех страницах через блок сообщений в `base.html`.

#️#️ 🚀 Запуск проекта
`python manage.py runserver`
