# Лабораторная работа №6
## Django REST Framework - Микросервисы для приложения голосований

### 🚀 Цель работы
Реализовать набор микросервисов для приложения **polls**, созданного ранее, используя **Django REST Framework (DRF)**.
Микросервисы должны обеспечивать аналитику, фильтрацию, визуализацию и экспорт данных о голосованиях, а также предоставить веб-страницу для взаимодействия с ними.

## 🧩 Структура микросервисов

Создано новое приложение **poll_analytics**, которое содержит 4 микросервиса.

| № | Название                  | Описание                                                                                           | URL                                |
|---|---------------------------|----------------------------------------------------------------------------------------------------|------------------------------------|
| 1 | **QuestionStatsAPIView**  | Возвращает статистику по выбранному голосованию - количество и процент голосов по каждому варианту | `api/question/<id>/stats/`         |
| 2 | **QuestionFilterAPIView** | Позволяет сортировать и фильтровать голосования по дате, популярности и числу голосов              | `api/questions/filter/`            |
| 3 | **QuestionChartAPIView**  | Создает диаграмму (SVG) с процентами вариантов ответов для выбранного голосования                  | `api/question/<id>/chart/`         |
| 4 | **QuestionExportAPIView** | Обеспечивает экспорт данных обо всех голосованиях в формате CSV или JSON                           | `api/questions/export/?format=csv` |

## 🖥️ Функционал страницы поиска голосований

Добавлена страница `search_polls.html` в приложении `polls`, доступная по адресу: http://127.0.0.1:8000/polls/search/

### 🔎 Возможности страницы:
- Поиск голосований с фильтром по дате и сортировкой по:
- - дате проведения
- - количеству голосов
- Отображение списка найденных голосований (динамически, без перезагрузки страницы)
- При клике на голосование:
- - справа отображается статистика (результаты голосов)
- - строится диаграмма на основе данных микросервиса
- Кнопки экспорта:
- - **Download CSV** - выгрузка результатов всех голосований
- - **Download JSON** - экспорт данных в JSON-формате

## ✅ Результат работы
В лабораторной работе реализованы микросервисы для анализа и визуализации данных о голосованиях.
Создан веб-интерфейс для работы с ними, обеспечивающий интерактивный поиск, отображение статистики и экспорт результатов.
