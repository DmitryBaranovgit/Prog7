# 🧩 Практическая работа: Авторизация через Google (OAuth 2.0) в Django

## 📄 Описание проекта
В ходе практической работы было реализовано подключение и настройка авторизации пользователей через **Google** с использованием протокола **OAuth 2.0**. Для интеграции применялась библиотека **django-allauth**, которая обеспечивает готовую систему входа чреез сторонние сервисы.

Проект представляет собой Django-приложение с системой аутентификации, позволяющей пользователям входить с помощью своей Google-учетной записи.

## 🚀 Этапы выполения работы

1.Добавление компонентов
В проект добавлены необходимые компоненты для работы с системой авторизации.

2. Подключение библиотеки Django Allauth
Выполнена установка пакета **django-allauth** и его интеграция в проект.
В настройках проекта добавлены необходимые приложения и параметры перенаправления после входа и выхода пользователя.

3. Добавление базового шаблона
В каталоге templates добавлен шаблон **base.html**, содержащий элементы интерфейса для входа, выхода и отображения состояния пользователя.

4. Регистрация и настройка проекта в Google Cloud Console
- Создан новый проект в Google Cloude Console
- Настроен экран согласия OAuth (OAuth consent screen)
- Создан идентификатор клиента OAuth 2.0 (Client ID и Client Secret)
- Добавлены разрешенные адреса (Redirect URL) для локального тестирования

5. Добавление данных клиента в Django admin
Через вдминку Django в разделе Social applications добавлено новое приложение Google с параметрами Client ID и Secret key, а также привязано к сайту example.com

6. Проверка работы авторизации
После запуска сервера и перехода по адресу /accounts/login/ отображается кнопка "Log in with Google". При нажатии выполняется перенаправление на страницу /accounts/google/login/ и если пользователь нажмет continue, то октрывается страница авторизации Google и выбора аккаунта.
После успешного входа пользователь перенаправляется в приложение /polls/.
☑️ Авторизация через Google успешно работает.

## ✅ Результат работы
В результате практической работы была успешно реализована и протестирована авторизация пользователей через Google с использованием протокола OAuth 2.0. Проект корректно выполняет вход через Google-аккаунт, интеграция с Django Allauth выполена успешно.
