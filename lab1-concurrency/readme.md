# Лабораторная работа: Параллельное и асинхронное программирование в Python

## [Часть 1. Численное интегрирование](lab1-concurrency/1-simple-integration)
В данной части реализуется численное интегрирование функции на заданном интервале методом прямоугольника. Рассматривается последовательная реализация в одном потоке, а также выполняется оценка времени вычисления с использованием модуля **timeit** для различных значений количества итераций. Целью является анализ производительности и зависимости времени выполнения от числа разбиений интервала.

## [Часть 2. Потоки в Python](lab1-concurrency/2-threading)
Часть посвящена изучению многопоточности в Python c использованием модуля **threading**. Реализуются примеры создания и управления потоками, синхронизация доступа к общим данным с помощью **Lock**, а также примеры многопоточного выполнения задач ввода-вывода и вычислительных операций. Отдельное внимание уделяется особеннстям работы потоков и ограничениям, связанных с **GIL**.

## [Часть 3. Concurrency и Futures](lab1-concurrency/3-concurrency-futures)
В данной части используется высокоуровневый интерфейс параллельного выполения из модуля **concurrent.futures**. Реализуется асинхронное численное интегрирование с применением **ThreadPoolExecutor и ProcessPoolExecutor**, выполняется сравнение производительности потоков и процессов, а также проводится анализ эффективности параллельных вычислений для **CPU-bound задач**.

## [Часть 4. Асинхронность](lab1-concurrency/4-async)
Часть посвящена асинхронному программированию с использованием библиотеки **asyncio**. Рассматриваются асинхронные функции, параллельное выполнение задач с помощью **asyncio.gather**, асинхронные **HTTP-запросы**, работа с базой данных, создание асинхронных веб-скраперов и взаимодействие между клиентом и сервером. Основная цель - изучение неблокирующей модели выполнения и работы с событиями.
